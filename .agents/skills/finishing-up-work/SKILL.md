# Finishing up work

Always open up a pull request. Monitor the workflows it triggered and fix any issues that arise. If the PR is blocked by a workflow, fix the issue and push a new commit to unblock it.

Avoid committing all the changes together. Instead, commit in logical units of work. Each commit should be a self-contained change that can be understood on its own.

## UI Work

Include screenshots and/or recordings of the UI changes in the PR description. If the changes are not visible, include a description of the changes and how to test them.

## Backend Work

Include a description of the changes in the PR description. If there were any architectural changes, include a diagram of previous and new architecture.
