# Emulator captures

These screenshots show the release APK running in an Android 14 phone emulator at 1080 × 2340. The dark-theme capture uses a system font scale of 1.3. The sketch is the app's editable example; the text-fit capture replaces its heading with a longer label to exercise wrapping.

The `viewport-phone-*` captures show version 0.2.0. Portrait captures use 1080 × 2340 pixels; `viewport-phone-landscape.png` uses 2340 × 1080. The text-size capture shows a 33-pixel label after returning from Desktop and rotating twice. The desktop, zoom, and dark-large captures show the same editable example at different canvas and viewing scales. Dark-large uses system font scale 1.3. Each PNG embeds its capture origin in metadata.
